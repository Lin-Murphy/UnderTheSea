# Ultrasound Reef — Step 1
Open Assets/Scenes/UltrasoundReef_Step1.unity and press Play. If the scene has not been generated, use Ultrasound Reef > Create Step 1 Scene (save any existing scene first).

Click Game view. Space advances: Enter > Gel > Probe > Inhale > Hold > Exhale > Farewell/wipe > Exit. All states remain in one scene. Left returns to previous main stage; P pauses visual motion; R restarts; Escape ends immediately. No timed progression or breath-holding countdown.

Stage 4 darkens on inhale, grows both coral proxies together and lights the jellyfish. Hold retains this state; Exhale restores daylight. Operator decides when to advance. Stage 5 combines farewell and gel wiping as one placeholder. Actual handshake/wipe alignment, fish return animation, AR transitions, AprilTag input, XR rig, controller buttons, audio and final art are not implemented.

Camera is a desktop framing preview, not a calibrated supine headset view. Mirror coral root is at world height 2m. All meshes are generated at Play time. This project currently has no OpenXR package or Quest configuration; desktop Play is not a headset deployment.
